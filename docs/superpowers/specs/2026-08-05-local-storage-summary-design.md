# 通用设置中的本地数据与存储摘要

## 目标

在「设置 → 通用」提供只读的本地数据占用信息，让用户无需打开 Finder 即可确认当前对话数据库及相关本地数据库的磁盘大小。

## 范围

- 新增一个「本地数据与存储」区块，置于通用设置的工具模型配置之后。
- 显示对话数据库（`core-v2.db`）大小、本地数据库合计大小，以及数据目录。
- 在首次进入页面和用户点击“刷新”时读取一次；不轮询、不写入数据库、不提供清理按钮。

## 数据与边界

主进程以 `app.getPath('userData')` 为唯一目录来源，只读取固定文件：`core-v2.db`、`context.db`、`knowledge.db` 与 `config.db`。每个数据库的统计包含同名的 SQLite `-wal` 与 `-shm` 伴随文件，使显示的占用更接近实际磁盘使用量。

文件不存在时按 0 B 处理；单个文件读取失败不会影响其他项，前端显示“暂时无法读取”并允许重试。路径不暴露为可编辑输入，也不会扫描用户目录中的其他文件。

## 架构

1. 主进程提供一个专用 IPC 查询，返回数据目录、核心对话数据库大小、各数据库大小及总大小。
2. preload 将该查询以受限的 `appStorage` API 暴露给渲染层。
3. `GeneralSettings.vue` 仅负责加载状态、错误状态、字节单位格式化与刷新交互。

该边界让磁盘访问保留在主进程，渲染层不获得路径读取能力。

## 验收与测试

- 主进程统计单元测试覆盖：主库、WAL/SHM 被计入；缺失文件为 0；读取异常会被隔离。
- 渲染层测试覆盖：通用设置包含摘要入口与刷新动作。
- 运行对应测试及 Web 类型检查。

## 非目标

本次不实现清理、迁移、备份、按会话拆分统计或自动告警。这些涉及数据生命周期的操作应在未来独立的存储管理能力中设计。
